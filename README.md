# How to run this app locally
  - Clone the repository on your CMD
      - `git clone https://github.com/ThaboSYLN/dhl-tracking-system.git` 
  - Navigate to your IDE terminal and create a virtual environment on the project's root
      - `py -3.12 -m venv venv`
  - Navigate to the virtual environment
      - `venv\Scripts\activate`
  - Install all requirements
      - `pip install -r requirements.txt`
  - Run the automation process and start the api
      - `py run.py`
